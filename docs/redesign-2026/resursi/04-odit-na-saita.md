# N4 — Одит на сайта за 2 минути

**Статус:** скоро. **Препоръчвам го като следващия** — 70% от кода вече съществува (`lib/leak.js` = Digital Leak Report).
**Услуга:** Изработка / поддръжка на сайт.
**Обещание:** „Скорост, SEO, мобилна версия — и колко запитвания губите заради тях.“

## Потребителски път

1. Поставя **адреса на сайта** (+ ниша от списък, нужна е за сметката).
2. 20–40 секунди прогрес („проверяваме скоростта на телефон…“).
3. Без имейл: **обща оценка 0–100** + 5 показателя като светофар:
   - скорост на телефон (PageSpeed Insights, mobile);
   - SEO основа (title, description, H1, schema, sitemap, индексиране);
   - мобилна версия и достъпност;
   - проследяване (GA4, Meta Pixel, събития за форма/телефон);
   - конверсия (телефон и CTA над сгъвката, форма, време за зареждане на формата).
4. С имейл: **пълен отчет** със списък поправки по важност + оценка „≈ X запитвания/месец губите“.

## Сметката „колко губите“

`загуба ≈ посещения/мес. × (конверсия_бенчмарк − конверсия_оценена)`

- Посещенията са по избор. Ако човекът не ги знае, ползваме диапазон по ниша.
- Конверсията се оценява от сигналите: всеки червен показател сваля с фиксиран процент (таблица в кода).
- Винаги показваме **диапазон** и пишем, че е оценка.

## Техника

| Част | Откъде |
|---|---|
| Сигнали (сайт, HTTPS, Pixel, реклами) | `lib/smart-reach/signals.js` → `scanSignals` |
| Скорост | PageSpeed Insights API (безплатен с Google API ключа, който вече е в de-os) |
| Оценка | `lib/smart-reach/score.js` → `applyScore`, `easyWins` |
| Публичен отчет | вече има `/r/<token>` в leak — ползваме го за пълния отчет |
| Лид | Smart Reach, `source: "resource:odit"` |

**Повторно всеки месец:** повторен скан и имейл „оценката ви е 61 → 64; остават 3 поправки“.

**Разход:** PSI е безплатен. Places не е нужен, когато имаме домейн. Практически $0.

## Мост към услугата

Бутон „Поправете ги вместо мен“ → анкета с `services=[site_support]`, а при оценка < 50 → `website`.

## Метрики

Сканирания · % с имейл · средна оценка · лидове за сайт / поддръжка.
